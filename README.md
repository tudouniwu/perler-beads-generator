# 拼豆图片生成网站

上传任意照片，一键生成可直接照着拼的拼豆图纸。

- 按品牌色号匹配：MARD / COCO / 漫漫 / 盼盼 / 咪小窝 / Perler / Hama / Artkal
- 每格标注色号，自动统计用豆量、成品厘米尺寸、需要几块 29×29 底板
- 我的库存：记下手头各色号有多少颗，自动算缺豆清单，一键复制采购清单
- 纯前端、图片只在本地处理，不上传服务器；导出 PNG / PDF / CSV 均无水印

## 使用

打开 `index.html` 即可使用，无需安装、无需后端。

上传照片 → 选择品牌和网格尺寸 → 生成图纸 → 导出或按清单备豆。

## 部署

静态单文件，可直接部署到 Cloudflare Pages、GitHub Pages、Vercel 等静态托管平台。
